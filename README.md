# Data Governance & Quality Assessment Project

Performed extensive data profiling, quality assessments, and automated cleaning pipelines on a large-scale Brazilian e-commerce dataset containing over 100,000 records.

## 🚀 Key Features & Implementation
* **Data Profiling & Quality Dimensions**: Evaluated over 100k transactions across core metrics including completeness, consistency, validity, and uniqueness.
* **Cleaning & Preprocessing**: Applied robust validation techniques to isolate anomalies, handle missing values, and enforce structure.
* **Governance Reporting**: Developed comprehensive governance documentation and automated visual reports to support compliance and strategic decision-making.

## 📂 Project Structure
* `data_profiling.ipynb`: Notebook exploring the dataset's initial health, schema validation, and anomaly detection.
* `data_cleaning_pipeline.py`: Automated cleaning and preprocessing script enforcing quality dimensions.
* `Governance_Report.pdf`: Business-facing documentation detailing the data quality framework and quality scorecards.
